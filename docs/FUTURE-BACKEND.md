# 私人家庭相簿規劃

本網站的 GitHub Pages 內容可由具備網址的訪客讀取。收藏與留言儲存在瀏覽器。相片 `visibility` 是預留的資料欄位，真正的 Public、Family Only、Parents Only 存取等級需要伺服器執行授權。靜態密碼、瀏覽器登入狀態、搜尋引擎設定及頁面隱藏都無法保護 GitHub Pages 上的素材。

## 正式版本

- 可保留 HTML 前端或改用 Angular，以 ASP.NET Core Web API 提供登入、家庭邀請、相簿與媒體操作。
- 使用 SQL Server 儲存家庭、成員角色、相簿、照片描述、故事、里程碑及稽核資料。每個資料列附家庭 ID，API 依成員關係與內容權限檢查所有讀寫。
- 在 Synology NAS 的受保護儲存區保存原圖和衍生圖。經授權後串流或簽發短效媒體網址，並納入撤回分享及快取策略。
- 上傳時限制類型與容量、檢查圖檔並移除 EXIF/GPS。記錄公開同意、刪除申請與稽核事件。
- 規劃原圖和資料庫的加密備份、異地備份、復原演練與版本追蹤。真實兒童照片、完整生日、學校與位置資訊應依實際授權最小化使用。
