# 視覺方向

預設採用日系生活雜誌。首屏搭配大字、暖米白留白、自然光攝影、微傾斜紙邊與小型印章。人物使用虛構角色插畫，照片採公開攝影示意並標示用途。

## 可選風格

| 風格 | 適合呈現 |
| --- | --- |
| 日系生活雜誌 · 已採用 | 自然光、留白、襯線標題、紙面與墨綠，適合長時間閱讀家庭故事 |
| 北歐粉彩 | 雲霧藍、灰粉與細邊框，適合較輕盈的成長紀錄。可使用 Pastel Memories |
| 手工拼貼 | 拍立得白邊與手帳票籤，適合相簿封面及首頁精選 |
| 夜間故事 | 深灰綠、暖褐與米色，適合在低光環境翻閱。可使用 Night Story |

## 字體與元件

- 大標題依序使用 Noto Serif TC、宋體、細明體、Georgia，正文依序使用 Noto Sans TC、微軟正黑體、蘋方和系統無襯線。使用裝置現有字體，離線時也能顯示。
- 主要按鈕 44px 起、12px 圓角。相簿卡 16px、雙寶卡及燈箱 20px。行動格線最少兩欄，630px 起三欄，960px 起桌機版面，容器上限 1240px。
- 照片卡保持焦點環與可見收藏按鈕。圖像裁切用於卡片，燈箱使用原比例檢視。
- 翻頁採短時間 CSS 透視；照片僅在指標移入時柔和放大。減少動態偏好會停用瀏覽器預設輪播及縮短動畫。
- 避免重度濾鏡、誇張玻璃光暈、塑膠質感、大量裝飾、假的親友身分和虛構的攝影署名。
