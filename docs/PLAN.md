# 木漏日小日子實作計畫

建立一本手機與桌機都能翻閱的雙寶成長紀念冊。使用 HTML、CSS 與傳統 JavaScript 指令碼，相對路徑可直接透過本機檔案或 GitHub Pages 開啟。

## 範圍與設計取捨

- 採用日系生活雜誌，搭配實體相簿的紙邊、跨頁感與自然攝影。另評估北歐粉彩、手帳拼貼和夜間閱讀，保留後兩種配色選項為 Pastel Memories 與 Night Story。
- 以 CSS 實作動態與相簿書版型，維持離線與低動態相容性。Three.js、Blender 與 Unreal Engine 為選用工具。
- 明確標示虛構人物及公開攝影素材。網站以示範用途公開，收藏、留言、近期閱讀與主題設定儲存在瀏覽器。
- 正式登入、雲端同步、影片編碼與專業印刷留待後續。

## 里程碑與驗收

1. 建立新目錄與 Git 儲存庫，撰寫日期及資料關聯測試，驗證閏年、月底、出生前與缺漏關聯。
2. 建立 CSS 主題、共用導覽、首頁與示範素材。驗收 2 位虛構角色、10 本相簿、48 筆照片、12 篇故事、15 筆里程碑及 6 種分類。
3. 建立照片牆、搜尋、篩選、收藏與放大檢視。驗收空結果、失效網址、分批顯示、鍵盤與觸控。
4. 建立時間軸、月曆、故事、相簿書及本機互動。驗收月份邊界、翻頁、列印與本機狀態。
5. 執行單元與瀏覽器驗證，檢查七種寬度、離線、相對路徑與隱私。完成維護文件及初始提交。
6. 確認新的遠端倉庫及分支，顯示 remote、branch、commit 後推送。啟用 Pages 並以公開網址驗證。

## 工作分解

- `assets/js/*-data.js` 管理示範內容及關聯，`core.js` 管理日期、搜尋及本機狀態。
- `ui.js` 提供共用元件，`gallery.js` 處理照片牆與燈箱，`pages.js`、`growth.js`、`book.js` 處理各頁。
- `assets/css/` 管理版面、三套主題與列印，`memories/` 存放可直接開啟的故事內容。

## 風險

- 公開照片素材需逐項記錄授權與來源。使用本機圖檔，降低外部圖片服務失效的影響。
- 本機檔案模式的儲存範圍由瀏覽器決定，跨頁設定與收藏以 HTTP(S) 驗收。
- GitHub Pages 需要遠端倉庫、推送權限及 Pages 設定權限。
