# 測試計畫

## 可重複執行

- `node --test tests` 驗證日期格式、閏年、月底月齡、跨年、出生前、搜尋、示範筆數、外部關聯及圖片檔案。
- `node --experimental-websocket tests/browser.cjs` 以獨立暫存瀏覽器設定檔和本機靜態子路徑測試。可透過 `ALBUM_BROWSER` 指定 Chrome 或 Edge 可執行檔。
- 瀏覽器測試檢查 360、375、430、768、1024、1440、1920px，含首頁、照片牆、時間軸、日曆、相簿書與 `file://` 入口。
- 檢查裝置上的主題持久性、手機選單、瀑布流、載入更多、搜尋、燈箱鍵盤與滑動、收藏、故事本機留言、相簿書翻頁及 A4 PDF。

## 首版驗證紀錄

- Node 內建測試通過 7 項，含兄妹與全家篩選、年齡階段及相簿排序。
- Chromium 直接開啟 18 個本機入口，在模擬 GitHub Pages 子路徑測試 5 種頁面和 7 種螢幕寬度。
- 實際走完手機選單、搜尋、載入更多、照片版型、放大檢視、Tab 焦點停留、Escape 與焦點恢復、觸控切換、輪播、收藏、主題、月曆、成長階段、故事留言與反應。
- 相簿書切換四宮格及翻頁，瀏覽器輸出 5 頁 PDF。自動測試使用 Chromium，實體裝置與螢幕閱讀器待手動檢查。

## 手動與實機

- [ ] Windows 使用檔案總管雙擊 `index.html`，確認登入前亦能開啟所有示範頁。
- [ ] 從相簿詳情切換四個照片版面，按左右箭頭、Escape，確認焦點回到開啟按鈕。
- [ ] 使用 Android Chrome 與 iOS Safari 檢查觸控、手機選單、燈箱和日期格。
- [ ] 使用鍵盤走讀頁首、搜尋、日曆、燈箱、故事與相簿書。使用 NVDA 或 VoiceOver 確認按鈕及動態狀態朗讀。
- [ ] 切換系統減少動態，確認首頁初始暫停自動播放，書頁保留導覽。
- [ ] 瀏覽器支援時，手動確認燈箱全螢幕進出和分享面板。
- [ ] 列印實體 A4 或檢視瀏覽器產生的 PDF，確認封面、目錄、內容、結尾及邊界。
- [ ] 在 GitHub Pages 網址檢查下層故事與圖片，確認首頁樣式、真實 404、手機導航和主題切換。
- [ ] 發布前確認素材授權、EXIF/GPS 與公開範圍。
